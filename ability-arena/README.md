# Ability Arena dashboard

A responsive training and assessment dashboard based on the supplied Ability Arena admin panel. Uses synthetic demonstration data, with no external backend or build dependencies.

Open `dist/index.html` in a browser, or serve the `dist` directory with any static HTTP server.

Features include reporting-period and chart controls, course search and status filtering, pagination, course creation and publishing, CSV export, module summaries, workspace settings, and responsive navigation. Training changes and settings persist in browser local storage. Other modules display read-only synthetic records.
